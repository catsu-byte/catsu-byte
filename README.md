## Building small, useful software

I'm learning software development by turning everyday problems into focused, privacy-friendly tools. My projects are intentionally lightweight: fast to open, easy to understand, and useful without an account.

### Selected projects

#### [PixelPress](https://github.com/catsu-byte/pixelpress)

Private image compression and resizing in the browser. Files never leave the device.

`JavaScript` · `Canvas API` · `PWA` · `Offline-first`

#### [Calcora](https://github.com/catsu-byte/calcora)

A keyboard-friendly calculator with a safe expression parser, local history, and offline support.

`JavaScript` · `Parser` · `PWA` · `Accessible UI`

#### [Focuslane](https://github.com/catsu-byte/focuslane)

A calm focus timer with custom sessions and private, local progress tracking.

`JavaScript` · `Local storage` · `PWA` · `Responsive UI`

### How I build

- useful before impressive
- local-first when a server is unnecessary
- small dependencies and readable code
- real progress instead of empty contribution commits
